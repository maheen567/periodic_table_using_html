# Periodic Table in HTML

- A periodic table of the elements built using only HTML, with no CSS or JavaScript.
- The main table shows elements 1 to 118 in their standard groups and periods, using table rows, cells, and `colspan` to create the gaps in the layout.
- The lanthanides and actinides are placed in a separate table below the main one.
- Created as a practice project to learn HTML table structure and page layout.
